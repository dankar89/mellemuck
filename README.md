# Mulle Meck på en ny dator

De gamla Mulle Meck-spelen från 90-talet, spelbara igen på Windows 10/11 och
Steam Deck. Samma spel som förr, men med skarpare bilder och utan krångel.

> **Testat på Windows och Steam Deck.** Det finns en Linux-version också,
> men den är inte testad på andra datorer än Steam Deck.

| Spel | |
|---|---|
| Bygg bilar med Mulle Meck | fungerar |
| Bygg båtar med Mulle Meck | fungerar |
| Bygg hus med Mulle Meck | fungerar |
| Upptäck rymden med Mulle Meck | kommer senare |

## Det här är nytt

- **Fungerar på nya datorer.** Ingen installation, ingen cd-skiva i
  datorn, inga kompatibilitetsinställningar. Spelen körs oförändrade, men
  buggarna som gjorde dem ospelbara på dagens Windows är fixade (till
  exempel havet i Bygg båtar).
- **Skarpare bilder (HD).** Spelets bilder ritas om i högre upplösning, på
  din egen dator. Byt mellan HD och originalbilderna med F6.
- **Handkontroll (inte så vältestat än).** Flytta handen med spaken, kör
  bilen och båten dit spaken pekar. Det är nytt och kan krångla; berätta
  gärna hur det går.
- **Steam Deck.** Kopiera över allt från datorn med en knapp, så hamnar
  Mulle Meck i Steam-biblioteket. Skärmtangentbordet kommer upp när du
  skriver ditt namn.
- **Pausmeny.** Spara, ladda, fönster eller helskärm och avsluta, med mus,
  tangentbord eller handkontroll.
- **Sparar av sig själv,** och varje spelare har sina egna sparningar, så
  syskon inte skriver över varandra.
- **Å, ä och ö** i namnen fungerar.
- **Ett startprogram för alla spelen.** Det hittar dina spel själv: skivan,
  en skivavbild (`.iso`) eller en `.zip`.

## Ladda ner

### ➜ [Ladda ner för Windows](https://github.com/dankar89/mellemuck/releases/latest/download/MulleMeck-Windows.zip)

(Linux, otestad: [MulleMeck-Linux.tar.gz](https://github.com/dankar89/mellemuck/releases/latest/download/MulleMeck-Linux.tar.gz).
Alla versioner: [Releases](https://github.com/dankar89/mellemuck/releases).)

**Spelen ingår inte.** Du behöver din egen kopia av spelet: skivan, eller en
skivavbild (`.iso`) eller `.zip` med spelet.

## Så här gör du

1. **Packa upp** zip-filen: högerklicka på den och välj **Extrahera alla...**
   Lägg mappen på till exempel Skrivbordet (inte i "Program Files").
2. Öppna mappen **MulleMeck** och dubbelklicka på **Mulle Meck.exe**.
   Säger Windows *"Windows skyddade datorn"*? Klicka **Mer information** och
   sedan **Kör ändå**. (Det står så för alla program som inte kommer från ett
   stort företag.)
3. Klicka **Hitta spelet**.
4. Klicka på den gula knappen **Spela**.

Nästa gång kan du starta ett spel direkt med **Bygg bilar.exe**, **Bygg
båtar.exe** eller **Bygg hus.exe** i mappen.

Skarpare bilder: klicka **Gör HD-bilder** (15-50 minuter per spel, du kan
spela under tiden). Allt annat, som Steam Deck och handkontroll, står i
**LÄS MIG.txt** i mappen.
